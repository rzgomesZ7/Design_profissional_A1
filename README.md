# Design_profissional_A1

## 📝 Descrição

O repositório **Design_profissional_A1** agrupa os projetos/exercícios da disciplina A1 de “Design Profissional” — armazenados na pasta `Materias`.  
Cada subprojeto busca aplicar conceitos de design, usabilidade e estruturação de páginas/aplicações web, com o objetivo de praticar técnicas de front-end e lógica de programação.

## 🎯 Objetivos dos projetos

- Praticar a estruturação de páginas e componentes com HTML e CSS.  
- Aplicar lógica de programação e interações com JavaScript (quando houver) para tornar as páginas dinâmicas ou interativas.  
- Organizar o código de forma limpa e mantendo separação de responsabilidades entre estrutura (HTML), estilo (CSS) e comportamento (JS/C).  
- Criar uma base de projetos simples que demonstre conhecimentos de front-end e lógica, para servir como portfólio pessoal ou apoio aos estudos.
